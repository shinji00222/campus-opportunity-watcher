# 校园机会提醒

高校竞赛、实习、出国机会定时提醒工具。学校和信息来源写在配置文件里，让 AI 读一遍 [AI_SETUP.md](AI_SETUP.md) 就能配好你的学校。（原本只有广工版，在某人的提醒下开了这个新仓库）

## 能做什么

- 每天定时检查学校官网和公开平台，汇总竞赛、实习、出国交流通知，检查完就退出，不常驻后台
- 有新通知时弹 Windows 通知，竞赛、出国排在前面；全国招聘平台的岗位只通知符合档案意向的，其余只在界面里显示
- 同一条通知改了标题或截止日期会再提醒一次
- 识别报名截止日期，过期的自动清理；没有截止日期的实习按发布日期 60 天清理
- 读取正文里的参赛对象、资格要求，按本机个人档案算匹配度
- 收藏、分类筛选、关键词搜索
- 内置国家大学生就业服务平台（可按省份筛选）、国际组织实习平台、蓝桥杯官网
- 系统代理开着就走代理，代理没开或连不上就自动直连

## 配置你的学校

已有学校：`schools/gdut`（广东工业大学）。

没有你的学校的话，把仓库交给 AI（Claude、Codex、Cursor 都行），跟它说：

> 读一下 AI_SETUP.md，帮我把这个工具配置成 XX 大学的。

它会帮你找通知页面、写 `schools/<学校>/school.toml`、试跑确认能抓到东西。也可以照着 `schools/_template` 自己写。

## 个人档案和意向关键词

界面上点“个人档案”，填学历、入学年份、语言成绩和**意向关键词**（逗号分隔）。档案只存在本机，用来做两件事：

1. 界面里按匹配度排序，并标出你不满足的条件（比如只招研究生、四六级分数线）。
2. 决定哪些新消息弹通知。

通知规则：

- 学校官网、学院、蓝桥杯这些来源，新消息都会通知（`notify = "all"`）。
- 国家大学生就业服务平台、国际组织实习平台每天几十条岗位，大多跟你的专业无关，默认只通知**命中意向关键词**的（`notify = "match"`），其余只在界面里显示。
- “命中”指：关键词出现在**标题**里，或者在**正文里出现至少两次**。正文只提一次的不算，因为常常是顺带一句，比如“通过互联网开拓客户”、公司介绍里的“工业互联网平台”。
- 英文关键词不分大小写，只按完整单词算：`AI` 能匹配“AI训练实习生”“使用AI工具”，不会匹配 unpaid、maintain。
- 硬条件明确不符（比如只招研究生）的不通知。
- 意向关键词留空的话不做过滤，所有新消息都通知。

### 关键词怎么选

原则：用**岗位名里会出现的词**，不要用行业大词。下表“慎用”一栏是拿 2026 年 10 月广东的 188 条实习岗位实测、会大量误命中的词；推荐词里有一部分（如 Java、FPGA）这批岗位里没出现，是按常见岗位名列的。

| 方向 | 推荐关键词 | 能抓到的岗位 | 慎用 |
|---|---|---|---|
| AI / 算法 | `AI,算法,大模型,数据标注,提示词` | 算法工程师、AI 工程师、AI 训练、数据标注、提示词工程师 | `人工智能`（岗位标题很少这么写，基本抓不到） |
| 软件开发 / 测试 | `软件,测试,前端,后端,Java,Python,程序员` | 软件实习工程师、测试工程师 | `开发`（会命中销售岗的“客户开发”）；`软件`（维修、短视频岗也常写“会用某某软件”） |
| 数据分析 | `数据分析,数据挖掘` | 数据分析师、电商数据分析 | `数据`（运营、财务岗几乎都写“数据”） |
| 硬件 / 嵌入式 | `嵌入式,硬件,单片机,FPGA` | 硬件工程师、嵌入式工程师 | `电子`（会命中“电子厂操作工”“组装焊接工”）；`电路`（维修、销售岗也常写） |
| 机械 / 自动化 | `机械工程师,PLC,CAD,机器人` | 机械工程师、自动化工程师 | `自动化`（会命中“自动化设备操作员”这类产线岗位） |
| 产品 / 运营 | `产品经理,产品助理,新媒体,内容运营` | 产品经理、新媒体运营 | `运营`（电商、带货、短视频岗非常多） |
| 设计 | `UI,交互设计,视觉设计,平面设计` | UI 设计师、平面设计 | `设计`（服装、硬件、生产岗都会命中） |
| 金融 / 财会 | `财务,会计,审计,投资银行,券商` | 财务专员、投行实习 | `金融`（标题里少见） |
| 外语 / 国际组织 | `翻译,外贸,英语`；国际组织平台可以加 `communications,research,finance` | 翻译、外贸、联合国机构的传播、研究岗 | `IT`、`data`（英文正文里太常见，几乎每条都命中） |

竞赛、出国交流的通知来自学校官网，不受这里影响；`海外交流` 这类词只影响界面里的排序。

填完后，到界面的实习分类里看一眼：命中的岗位排在前面，点开条件能看到“符合意向：……”。发现误命中，就把那个词换成更具体的岗位名。

## 从源码运行

需要 Python 3.11 或更高版本。

```powershell
python -m pip install -r requirements.txt
python run_watcher.py --school gdut                 # 打开界面
python run_watcher.py --school gdut --probe         # 试跑所有来源，不写状态
python run_watcher.py --school gdut --scheduled     # 静默检查一次
```

装成每天自动检查（上午 8 点、晚上 8 点）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -School gdut -FromSource
```

## 打包 EXE

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name CampusOpportunityWatcher --paths src --collect-all winotify `
  --add-data "schools;schools" run_watcher.py
```

发布包里放 `dist\CampusOpportunityWatcher.exe` 和 `scripts\` 下的安装、卸载脚本。

## 更新

程序每天检查一次 GitHub 上有没有新版本，有的话弹一次通知，界面右上角也会出现“新版本”按钮，点开就是下载页。更新时关闭程序，下载新的 ZIP，再运行一次安装脚本就行，个人档案、收藏和历史都会保留。

不想检查更新的话，设置环境变量 `CAMPUS_WATCHER_NO_UPDATE_CHECK=1`。手动查一次：`python run_watcher.py --check-update`。

## 隐私

个人档案、收藏、检测记录和日志只存在本机 `%LOCALAPPDATA%\CampusOpportunityWatcher\<学校id>\`，不会上传。工具只读公开网页，不登录任何系统。

## 局限

只能抓公开网页。微信群、公众号、图片和附件里的要求、需要登录的平台都抓不到。网站改版也可能让某个来源失效，失效时检测结果会显示来源错误。报名前请以原通知为准。
